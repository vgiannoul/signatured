# .ai Directory

This directory contains AI agent-specific files for the signatured project.

## Contents

- **AGENTS.md** - Comprehensive instructions for AI agents working on this project
- **plans/** - Directory for storing task plans and work breakdowns
- **memory/** - Directory for storing context from previous AI sessions (if needed)

## Purpose

This directory provides a standardized way for AI agents to:
- Understand project structure and conventions
- Follow proper release and versioning processes
- Maintain documentation consistency
- Apply best practices for development workflow

## Usage

AI agents should read `AGENTS.md` as the primary source of truth for project-specific instructions that supplement global AI configuration.
