# Plans Directory

This directory is reserved for storing task plans and work breakdowns created by AI agents.

## Purpose

AI agents can use this directory to:
- Break down complex tasks into manageable steps
- Track progress on multi-phase projects
- Store implementation plans for future reference

## Naming Convention

Use descriptive names with timestamps:
- `feature-gcs-templates-2026-03-19.md`
- `refactor-auth-flow-2026-04-01.md`
- `bugfix-template-parsing-2026-03-15.md`

## Format

Plans should include:
1. **Objective** - What needs to be accomplished
2. **Approach** - How it will be done
3. **Tasks** - Specific steps with completion status
4. **Dependencies** - Prerequisites or blockers
5. **Testing** - Verification strategy
6. **Documentation** - What docs need updates

## Retention

- Keep recent plans (last 30 days)
- Archive or remove completed plans older than 30 days
- Preserve plans for major features/refactors as historical reference
